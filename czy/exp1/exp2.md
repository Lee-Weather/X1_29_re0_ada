### §10 三条结论

1. **弧线是「LCP 加码」与「踝增益下调」的独立副作用，且近似叠加**。
   - KP 28 单独贡献 +16~22°；LCP 3e-5 单独贡献 +10~23°；两者同开达 +33~36°（约为两者之和量级）。
   - **修正**：exp2.2b 阶段据单臂数据推断"弧线只来自 KP 28"，**该归因错误**（已在 §6 标注）。**双变量归因必须靠 2×2 才能完成**——这是本次拆解实验最重要的方法论收尾。
2. **exp2.0 配置（LCP 1e-5 + 踝 KP 35）是四个格子中唯一的可用解**。其余三格全部 NO-GO，且各自以不同机制失效：
   - exp2.2a（LCP 3e-5）：弧线 + 高速推进不足 + 踝 pitch 颤振反升 + Δaction 翻倍
   - exp2.2b（KP 28）：弧线 + 踝 roll 稳态误差饱和（0.316 rad）+ 跟踪崩塌
   - exp2.1p（两者同开）：失效最严重（弧线 +33~36°、reward -16%）
3. **"更平滑"不等于"更好"**。exp2.2a/exp2.1p 的 jac_frob 更低（2.462 / 2.371 vs exp2.0 的 2.933），但任务表现与关节颤振全面劣化。**LCP 提高权重后，策略是把平滑度换到手了，代价是动作通道变抖（Δaction ↑）与偏航失稳**——LCP 的"平滑"在权重超限时会转化为另一种形式的抖动。

### §11 后续建议

1. **LCP 权重上限已探明**：1e-5 可用，3e-5 有害 → 若还要寻优，只应在 **1e-5 ~ 2e-5** 区间轻推，且必须监控 yaw 漂移与 Δaction（而非只看 jac_frob）。
2. **踝增益保持 35**：28 明确不可用；如需微调，中间值（31~32）与 35 之间没有明确动机，除非先解决弧线问题。
3. **弧线（yaw 漂移）现在是首要阻塞项**：它是所有增强尝试的共同副作用，也是 exp2.0 想进一步优化时最先要守住的指标。建议下一轮**不再改动 LCP/增益**，转而：
   - 要么**先把弧线指标做成显式的验收闸门**（回放 yaw 漂移 ≤7° 才允许通过），
   - 要么**专门研究弧线的成因**（现有证据：exp2.0 零弧线，任何偏离都出弧线 → 提示 exp2.0 处于某个**窄的稳定域**内，弧线对超参高度敏感）。
4. **回放分析脚本应固定输出踝稳态误差**（本轮的 exp2.2b 靠它定位了饱和机制）。

# exp2.2a 抖动溯源（2026-09-29，用户反馈"视频中看抖动严重"）

### §1 现象与前提

| **pos（关节实际）** | 1.5 Hz / 5.8% | 1.5 Hz / **5.0%** |

| **torque（PD 输出）** | 1.5 Hz / 12.3% | 1.5 Hz（**9.1 Hz 升为强次峰**）/ 46.9% |

**关键读法**：
- 振荡**出现在 action 里**（67% >5Hz），说明**源自策略，不是机械共振**。
- **关节实际位置几乎不动**（pos 的 >5Hz 仅 5.0%，与 exp2.0 的 5.8% 同级）。
- 力矩却把 9.1 Hz 原样吐出（46.9%）——正是此前记录的「**踝是力矩主导**」特性：`τ ≈ KP×(pos_des − pos)`，指令的高频成分变成扭矩而非运动，**PD 环对指令高频没有任何衰减**。

### §3 振荡在各关节的分布（力矩 >5Hz 能量占比）

| 关节力矩 | exp2.0 | **exp2.2a** | 倍数 |
| --- | --- | --- | --- |
| **膝 pitch** | 36.7% | **91.5%** | 受害最重 |
| **髋 pitch** | 8.6% | **69.5%** | 8× |
| 踝 pitch | 12.3% | 46.9% | 3.8× |
| 踝 roll | 14.3% | 14.5% | 无变化 |

全关节力矩抖动幅度：髋pitch 2.60→**7.86 Nm（3.0×）**、膝 9.71→**21.42 Nm（2.2×）**、髋roll 6.21→9.34（1.5×）。

**振荡集中在膝与髋 pitch**——正是视频中最显眼的两条大腿，所以观感抖动强烈。

### §4 结论与图

**exp2.2a 的视频抖动 = 策略输出中的 9.1 Hz 极限环，经 PD 无衰减地转化为膝/髋/踝力矩。**

诊断图：[jitter_diagnosis.png](file:///e:/X1/F1_one/X1_29_re0_ada/czy/data/exp2.2a/jitter_diagnosis.png)

### §5 机理讨论（对 LCP 的重要认识）

**LCP 的 `∂logπ/∂s` 约束的是「空间敏感度」，不约束「由自身历史驱动的极限环」。**

- 极限环中，观测 `s` 本身就在振荡；策略只需在每个点上满足 `∂μ/∂s` 小，整条轨迹仍可在 9.1 Hz 上持续抖。
- 这正是 exp2.2a 的**悖论**来源：`jac_frob` 更低（2.462 vs exp2.0 的 2.933，"更平滑"），但 Δaction 翻倍、力矩高频能量翻数倍（"更抖"）。
- ⇒ **`jac_frob` 不能作为"策略是否抖"的代理指标**；必须同时看时间域指标（Δaction、τ 高频能量 / 谱峰）。

### §6 对后续的意义

1. **LCP 权重 3e-5 引入了一个 9.1 Hz 极限环**，这是 exp2.2a / exp2.1p 失效的直接机制（而非此前推测的"单纯变软"）。
2. **9.1 Hz 值得单独追踪**：它接近控制频率 100 Hz 的 1/11，但更像是"策略-历史观测"闭环的自激频率；若后续实验再出现，可直接查该峰。
3. **验收补充建议**：在回放脚本中加入「**力矩 >5Hz 能量占比**」与「**谱峰定位**」，比单看 `jac_frob` 更能抓到这类失效。

**为什么时间域惩罚是唯一有直接依据的杠杆**：

- 实测 `Mean episode rew_action_smoothness = **-0.0050**`（权重 `-0.002` → 原始项 ≈ 2.5）。参照最大正项 `rew_ref_joint_pos = 1.337`，**它只占 0.37%** —— 这个惩罚实质上等于关着。

  - `term_1 = Σ(a_t − a_{t−1})²`（一阶差分）
  - `term_2 = Σ(a_t + a_{t−2} − 2a_{t−1})²`（二阶差分）
  - `term_3 = 0.05·Σ|a_t|`（幅值）
- **选择性计算**：对 100Hz 采样，一阶差分对频率 f 的响应 ∝ sin(πf/100)。
  - 9.1 Hz 分量：sin(π·9.1/100) = 0.284
  - 1.4 Hz 步态分量：sin(π·1.4/100) = 0.044
  - ⇒ **一阶项对 9.1 Hz 的敏感度是步态分量的 6.5 倍（按平方计 42 倍）；二阶项更是 (6.5)⁴ ≈ 1700 倍**。
  - 即：**该惩罚天生专门打击高频颤振，几乎不动步态** —— 正是我们想要的。

**exp2.3b 想降抖，实际把踝/髋/膝的力矩高频能量全部推高，并把踝振荡从 1.5 Hz 搬到 5.7 Hz。** 训练侧还付出末期均值 **−30%**（130.61 vs 185.87）的代价。

### §4 统一机理：**所有"平滑化"干预都会造出一个新的中频极限环**

| 干预 | 手段层级 | 踝力矩/action 谱峰 | τ高频结果 |
| --- | --- | --- | --- |
| exp2.1 LPF fc=10Hz | 执行层滤波（改观测+奖励） | **6.5 Hz** | 4.43/10.43 ❌ |
| **exp2.3b smooth −0.05** | **MDP 一阶时间惩罚** | **5.7 Hz** | **5.83/8.73** ❌ |
| exp2.2a LCP 3e-5 | 算法层二阶梯度正则 | action 峰 **9.1 Hz**；力矩 9.1 Hz 为强次峰 | 3.42/7.15 ❌ |
| exp2.0（基线） | 无 | 1.5 Hz（步态） | 3.01/4.93 ✅ |

**四次尝试、三种不同层级的手段（执行层滤波 / MDP 时间惩罚 / 算法层空间正则），全部以"约束动作变化"的方式触发新极限环。** 提示：**限制策略的动作自由度并不消除振源，而是把振源推到另一个频率**。这否定了"用正则项/滤波器压踝抖"这一整类路线。

### §6 方法论结论：单次回放的判读边界

**指标稳定性排序**（依据两次同配置样本 exp2.0 / exp2.3a）：

| 稳定性 | 指标 | 两次样本 |
| --- | --- | --- |
| ✅ **稳定** | 踝 τ高频（RMS） | 3.01/4.93 vs 3.25/5.01（±2~8%） |
| ✅ 稳定 | 膝力矩 >5Hz 能量 | 36.7% vs 36.4% |
| ✅ 稳定 | 踝力矩谱峰 | 1.5 Hz vs 1.5 Hz |
| ⚠️ 中等 | jac_frob | 2.933 vs 3.526（+20%） |
| ❌ **不稳** | yaw 漂移 | 差 4.5~11.7° |
| ❌ 不稳 | track | 差 7~9pp |
| ❌ 不稳 | 踝稳态误差 | 0.181 vs 0.240（+33%） |
| ❌ 不稳 | 髋力矩 >5Hz 能量 | 8.6% vs 24.3%（2.8×） |
| ❌ 不稳 | 末点 reward | run 内波动跨度达 42（157~199） |

**规则（后续实验必须遵守）**：
1. **主判据只用稳定指标**：踝 τ高频、膝 >5Hz 能量、踝谱峰；`jac_frob` 仅作参考。
2. **yaw 漂移 / track / 末点 reward 不能单独作为通过依据**，必须与同批复跑对照。
3. **关键结论至少需要 2 次复跑**（本轮以前 n=1，已导致 §5 中的错误结论）。

### §7 最终裁决

**exp2.3b = NO-GO**：既未降抖（τ高频反升 75%、新增 5.7 Hz 极限环），又在训练侧损失 30% 回报，并触犯踝稳态误差止损线。

**同时触发方案 §9 退出条件** —— 时间域惩罚杠杆**同样无效且同样引发新振荡**。故：

> **exp2.0 是当前配置空间内踝抖问题的局部最优；"用正则/滤波约束动作以压踝抖"这一整类路线（执行层滤波、MDP 时间惩罚、算法层空间正则）已被三轮实验证伪。**
